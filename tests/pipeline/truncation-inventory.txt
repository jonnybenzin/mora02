# Every place in the pipeline code that shortens something.
#
# The rule this file enforces: a cut that a human could mistake for the whole
# thing must ANNOUNCE itself. Six of the nine defects of 26 August 2026 were not
# malfunctions but silences, so a cut without a word is treated as a defect.
#
# Format:  <path> | <distinctive text of the line> | <kind> | <reason>
#
# Kinds:
#   announced     a text value IS shortened - the code must say so nearby
#                 (a truncated flag, a length, a visible note). Verified.
#   data-limit    a real technical ceiling on a value, adjustable and reported.
#                 Verified like "announced".
#   listing       a number of items, not the inside of a value. Nothing to hide.
#   identifier    a hash or slug cut to a fixed width. Not content.
#   formatting    a date or label sliced for shape, not for length.
#   storage       a field limit imposed by the store, not by us.
#
# A cut found in the code but missing here fails the test. Classify it, give the
# reason in one line, and the entry becomes the record of the decision.
